## The line

> I ran a simulation of tonight one million times. In every single one, you say yes — so shall we skip to the part where I buy you a drink?

Why this line: the joke grows out of being a machine — a robot that simulates the evening a million times before speaking — instead of a human line with a beep pasted on. The turn is the shortcut: the simulation already settled the outcome, so the robot skips the small talk and goes straight to the drink. One line, no padding, and a confident, charming ask rather than anything creepy.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt`. It checks the line first: a single line of 1–200 characters, so the gate can never see an invalid entry. Run it locally with:

```sh
ENTRY_OUTPUT=/tmp/entry.txt node main.ts
```
